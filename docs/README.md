
# Project Documentation

Thư mục này lưu trữ các tài liệu kỹ thuật và minh chứng cho quá trình triển khai dự án **Olist E-Commerce End-to-End Data Analytics**.

## MongoDB Database Documentation

Tài liệu trình bày quá trình xây dựng cơ sở dữ liệu MongoDB từ bộ dữ liệu Olist, bao gồm:

- Chuyển đổi dữ liệu CSV sang JSON bằng Python.
- Tổ chức dữ liệu trong MongoDB Atlas với 5 collections.
- Kiểm tra dữ liệu và tạo indexes.
- Minh chứng quá trình xây dựng cơ sở dữ liệu phục vụ ETL sang SQL Server.


**Tài liệu:** [Xem tài liệu xây dựng cơ sở dữ liệu MongoDB](<1. MINH CHỨNG XÂY DỰNG CƠ SỞ DỮ LIỆU MONGODB.pdf>)
